### Steps
Install:

Create a folder, e.g. gmail-yellow

Save the two files below into it (exact names, not .txt)

Open chrome://extensions, turn on Developer mode (top right)

Click Load unpacked, select the folder

Refresh Gmail

* star color settings are configurable directly in gmail's settings
